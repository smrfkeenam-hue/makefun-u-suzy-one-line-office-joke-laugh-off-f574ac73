Entry for the [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) on [make.fun](https://make.fun).

The program writes one original one-line office joke to `/output/entry.txt`:

> The office printer finally jammed on something important: my resignation letter.

The joke takes the most reliable office machine — the printer that always jams — and gives it one job it finally refuses: the resignation letter. One read, one twist, no setup to explain.
